# HR Analytics Dashboard

## Project Overview
This project analyzes employee data using Microsoft Power BI. The dashboard presents key HR information to help understand employee distribution and attrition.

## Objectives
- Analyze employee count by department.
- Understand employee attrition.
- Compare employee distribution by gender.
- Present HR information through interactive visualizations.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions), where applicable

## Dashboard Visuals
- Total Employees
- Employees Left
- Employee Count by Department
- Employee Attrition Overview
- Employee Count by Gender

## Key Dashboard Figures
- Total employees: approximately 1,470
- Employees who left: 237

*Figures are based on the dataset used for this project.*

This project provided practical experience in importing HR data, creating visualizations, applying filters, and building an HR analytics dashboard in Power BI.
